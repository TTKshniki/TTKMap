# TTKMap development demo

The foundation exposes `/healthz`, organizer session endpoints and the first map/document/public route APIs. Use the Docker commands in `AGENTS.md` after installing Docker Desktop or Docker Engine. Create the first organizer with the CLI command; no credentials are committed.

The complete demo becomes available when the feature tasks in `TASKS/manifest.json` are implemented. The required demonstration uses HTTPS for camera access, a real worker and real media files. A failed stitching job remains visible as failed and can be retried or replaced with a separately uploaded ready panorama.
