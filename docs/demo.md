# Экспертная демонстрация TTKMap

## Эталонная модель

Каноническая карта: **TTK Digital Campus · эталонная демо-модель**.

- Публичная ссылка: `http://localhost:8000/m/ttkshowcampusmapdemoaaaaaa`
- Вход для организатора: `http://localhost:8000/organize`
- Карта содержит план подложки, пять помещений/зон, шесть POI разных категорий, граф проходов, четыре связанных панорамы и направленные переходы между ними.
- В публичном просмотре доступны переключение 2D/3D, фильтрация и выбор POI, построение маршрута, виртуальный проход и панорамные хотспоты.
- План и 360°-сцены создаются как **синтетические иллюстрации** для показа интерфейса. Это не фотографии площадки и не результат реальной съёмки или Hugin stitching.

## Подготовка локального стенда

Демонстрационный seed создаёт известную учётную запись, поэтому включайте его только в локальном/изолированном demo-окружении — никогда в production.

1. В `.env` установите `TTK_ENV=demo` и `TTK_AUTO_SEED=1`.
2. Запустите `docker compose up -d --build api worker` и дождитесь `http://localhost:8000/healthz`.
3. Для уже работающей базы выполните `docker compose exec api python -m backend.app.cli seed-demo`. Seed добавляет недостающую эталонную карту и не удаляет существующие карты.
4. Откройте публичную ссылку выше. Для organizer-flow используйте только локально: `alexey@ttk.ru` / `ttkmap-organizer-2026`.

Если browser entrypoint уже открыт, обновите его с очисткой кэша. При изменениях frontend пересоберите API image: SPA включается в него на этапе Docker build.

## Рекомендуемый сценарий показа

1. Открыть эталонную ссылку без входа и переключить `3D изометрия` ↔ `2D план`.
2. Выбрать POI в списке или на карте, применить категории/поиск, открыть карточку.
3. Построить маршрут от ресепшена к конференц-залу; показать длину и доступные шаги 360°-прохода.
4. Открыть панораму, пройти по хотспотам и вернуться к той же карте.
5. Показать стабильную публичную ссылку и `/embed/:slug`.
6. В локальном organizer-сеансе показать редактор, сохранение/публикацию и серверную изометрическую GLB-модель. Для съёмки кадров камерой телефона необходим HTTPS.

Съёмка мобильной камерой, реальная сборка панорамы, офлайн-кэш, аналитика, AI-распознавание плана и многоэтажность проверяются отдельно. Не выдавайте synthetic illustration или этот demo seed за результаты этих сценариев.
