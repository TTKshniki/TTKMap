# TTKMap — Карта пространства

Хакатонный проект по кейсу ТТК: создание и просмотр карт помещений с панорамами и навигацией.

- [Спецификация](specification.md)
- [Исходное ТЗ](docs/reference_raw.md)
- Hub команды: https://vibehubik.mooo.com

## Подключение команды

После создания проекта лидер выдаст invite-код. Выполняйте команды из корня этого репозитория:

```bash
vibeteam join VIBE-XXXXXXXX --hub https://vibehubik.mooo.com --role frontend --nickname YOUR_NAME
vibeteam list
vibeteam
```

Для backend используйте `--role backend`. AI-ключ и ключ создания проекта участникам не нужны.

Контракты и задачи появятся после запуска лидерского консилиума. Команды запуска приложения будут добавлены после выбора стека.
